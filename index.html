Template Customization & GitHub Deployment Guide

1. Running Anywhere on Any System (Zero Dependencies)

This portfolio is engineered as a 100% self-contained single-file architecture (index.html). You can double-click it on Windows, macOS, or Linux in any modern browser, or serve it locally via Python (python3 -m http.server 8000) or VS Code Live Server.

2. Customizing Photo, Name, Academics, Skills & Projects

  • Click "Customize Template" in the top navigation bar.
  • Upload your portrait photo, edit your name, bio, academic degrees, courses, certifications, and projects.
  • Click "Download Standalone index.html" to export a ready-to-host file with your custom data and photo baked directly into the code.

3. Step-by-Step GitHub Pages Deployment

# Step 1: Create a folder and place your exported index.html inside it
mkdir my-portfolio && cd my-portfolio

# Step 2: Initialize Git and commit your portfolio
git init
git add index.html
git commit -m "Initial portfolio release"

# Step 3: Push to GitHub (replace YOUR_USERNAME)
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_USERNAME.github.io.git
git push -u origin main

Once pushed, go to your GitHub Repository → Settings → Pages → select branch main and folder / (root) → click Save. Your live portfolio URL will be active within 60 seconds!
