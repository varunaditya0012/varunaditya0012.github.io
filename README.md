## ✨ Features

- **Interactive Timeline Scrub**: Interactive 3-stage timeline frame navigation (Creative, Full Stack, Systems).
- **Glassmorphic Hero & Spotlight**: Dynamic radial gradient spotlight, 3D perspective portrait stage, and responsive interactive cards.
- **Project Showcase**: Rich interactive project previews with live demo and source code links.
- **In-Browser Customization**: Live customization panel to preview template tweaks and content changes.
- **Client-Side & Zero-Dependency**: Pure vanilla JavaScript and Tailwind CSS — zero build steps, instant load times on GitHub Pages.

## 🛠️ Tech Stack

- **Styling**: Tailwind CSS
- **Typography**: Inter & JetBrains Mono (Google Fonts)
- **Deployment**: GitHub Pages (via `main` branch)
